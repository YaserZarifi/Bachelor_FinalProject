# فهرست نمادها

## نشانه‌های اختصاری

| نشانه‌ی اختصاری | معادل کامل | برابر فارسی |
|---|---|---|
| API | Application Programming Interface | واسط برنامه‌سازی کاربردی |
| ASGI | Asynchronous Server Gateway Interface | واسط دروازه‌ی سرور ناهم‌زمان |
| CORS | Cross-Origin Resource Sharing | اشتراک منبع میان‌مبدأ |
| CRUD | Create, Read, Update, Delete | عملیات پایه‌ی داده |
| DRF | Django REST Framework | چارچوب ساخت واسط برنامه‌سازی روی جنگو |
| ERD | Entity-Relationship Diagram | نمودار موجودیت-رابطه |
| GeoJSON | Geographic JSON | قالب استاندارد داده‌ی مکانی |
| GIS | Geographic Information System | سامانه‌ی اطلاعات جغرافیایی |
| GPS | Global Positioning System | سامانه‌ی تعیین موقعیت فراگیر |
| JWT | JSON Web Token | نشانه‌ی احراز هویت بدون‌حالت |
| LLM | Large Language Model | مدل زبانی بزرگ |
| NLP | Natural Language Processing | پردازش زبان طبیعی |
| ORM | Object-Relational Mapper | نگاشت شیء به رابطه |
| REST | Representational State Transfer | سبک معماری واسط‌های وب |
| RTL | Right-to-Left | راست‌به‌چپ |
| SPA | Single-Page Application | برنامه‌ی تک‌صفحه‌ای |
| SRID | Spatial Reference System Identifier | شناسه‌ی سامانه‌ی مرجع مکانی |
| SVC | Support Vector Classifier | دسته‌بند بردار پشتیبان |
| SVM | Support Vector Machine | ماشین بردار پشتیبان |
| TF-IDF | Term Frequency–Inverse Document Frequency | بسامد واژه در بسامد وارون سند |
| WGS-84 | World Geodetic System 1984 | سامانه‌ی مرجع جهانی مختصات |
| WS | WebSocket | پروتکل ارتباط دوسویه‌ی بلادرنگ |

## نمادهای لاتین

| نماد | معنی |
|---|---|
| w | وزن یک کلیدواژه‌ی بحرانی در واژه‌نامه‌ی تشخیص فوریت (عددی میان ۱ تا ۳) |
| S | امتیاز بحرانِ متن گزارش؛ مجموع وزن کلیدواژه‌های یافت‌شده در متن |
| c | ضریب اطمینان دسته‌بند محلی برای دسته‌ی برگزیده (عددی میان ۰ تا ۱) |
| n | طول n-گرمِ نویسه‌ای در بردارسازی متن (در این پیاده‌سازی ۲ تا ۴) |
| C | ضریب تنظیم دسته‌بند بردار پشتیبان خطی |
