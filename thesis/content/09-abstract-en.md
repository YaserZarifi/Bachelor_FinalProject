# Abstract

The purpose of this project is to design and implement a digital, location-aware and real-time platform for reporting urban maintenance problems and following up on their resolution; a platform that simultaneously serves two needs: transparency and continuous feedback for the reporter, and structured, reliable data for municipal decision makers. The necessity of this work arises from the fact that common reporting practices lack any feedback loop and rely on entirely manual triage, which both reduces the motivation to participate and increases the processing burden on the operator.

The implemented system is a modular monolith built on the Django framework and its REST framework, serving three clients through standard interfaces: a citizen web application, an administrative dashboard and a native mobile application. The data core is built on the PostGIS spatial database so that geographic queries run directly at the database level and data is exposed to the clients in a standard spatial format. The lifecycle of every report is governed by a guarded state machine, and each status change is delivered to the reporter both over a real-time bidirectional channel and through a mobile push notification. To reduce the manual triage burden, a Persian natural language processing module determines the topical category and the urgency of each report by combining weighted crisis keywords, a local classifier, and a large language model that is used as a fallback whenever confidence is low. Report authenticity is secured through a triad of in-app camera capture, a client-side integrity hash and write-once capture metadata, while an offline-first architecture enables reporting without connectivity followed by automatic synchronization.

The evaluation was carried out along four axes: live execution of the main scenarios, testing of the programming interfaces, unit testing of the intelligent module, and measurement of the classifier accuracy. The local classifier reached an accuracy of 73.7 percent with a standard deviation of 7.4 percent under five-fold cross-validation on a corpus of 95 samples, and all four key scenarios were executed successfully on the implemented version. It is concluded that combining a spatial database, real-time communication and automatic text analysis yields a platform that closes the feedback loop and removes a substantial part of the manual triage; at the same time, the small size of the training corpus and the absence of load testing remain the main limitations of this version and the first priorities for future work.

**Keywords:** Citizen Reporting, Spatial Database, Persian Natural Language Processing, Real-time Communication, Offline-First Architecture
